# Marne Saunders learning dashboard

Public learning edition **SP3.22-P2**, derived from unchanged SP3.22.

Home/About and all seven learning activities are retained. Browser calculations are illustrative, not calibrated forecasts.

Rainfall, flow, dam-survey and related prepared inventory extracts are **not final**. Information Pack dam counts and water-use summaries are **preliminary**. Retain original reporting dates, units, source grades, gaps and sampling limitations. Display permission does not establish scientific review, model calibration or agency endorsement.

Unpublished agency draft material and the unresolved reproduced geometry reference image are excluded. Public reports are linked, not bundled. The prepared JSON downloads carry the same status as the plots.

This repository contains built website files only, not the development master. No raw archives, internal PDFs or QA records should be uploaded. The four JSON files under `evidence/` are the specifically authorised prepared extracts, not new raw-data releases.

Use the existing GitHub Pages publishing settings. The directory structure must be kept intact. Project illustrations are retained with project-owner approval; no blanket licence is granted for third-party material.
